# 🤖 Chatbot de Adopción Responsable

Este proyecto consiste en un chatbot simple desarrollado con **HTML, CSS y JavaScript**, cuyo objetivo es responder preguntas frecuentes relacionadas con la adopción de animales.

El chatbot está diseñado aplicando **principios de accesibilidad web**, estructura semántica y buenas prácticas de desarrollo frontend.

---

## 🛠 Tecnologías utilizadas

- HTML5 (estructura semántica)
- CSS3 (estilos, responsive y modo oscuro)
- JavaScript (lógica del chatbot)

---

## ♿ Accesibilidad

El proyecto cumple con los siguientes criterios de accesibilidad:

- Idioma del documento definido (`lang="es"`)
- Uso de texto en otro idioma con `lang="en"`
- HTML semántico (`main`, `section`, `form`, `label`)
- Imágenes con atributo `alt`
- Formulario accesible con `label` y `for`
- Uso de `aria-label` y `aria-live`
- Contraste adecuado de colores
- Navegación accesible con teclado

---

## 🤖 Funcionalidades del chatbot

- Responde preguntas predefinidas
- Muestra imágenes de perros y gatos disponibles para adopción
- Galería visual dentro del chat
- Manejo correcto del formulario
- Respuesta automática a preguntas no reconocidas
